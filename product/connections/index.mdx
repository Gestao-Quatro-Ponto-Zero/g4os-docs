Há duas escolhas diferentes no G4 OS: **qual IA vai trabalhar** e **quais ferramentas ela pode usar**.

| Quero… | Onde configurar |
| --- | --- |
| Escolher o modelo ou provedor da conversa | [Configurações > IA](/support/ai) e seletor de IA da sessão |
| Usar e-mail, agenda, documentos ou CRM | [Ferramentas > Conexões](/support/sources) |
| Usar um especialista criado no workspace | [Ferramentas > Agentes](/support/agents) |
| Gerar imagens ou usar capacidades gerenciadas | [Agentes gerenciados](/product/connections/managed-agents) disponíveis no catálogo |

## Comece pelas conexões gerenciadas

Elas oferecem autenticação guiada para serviços conhecidos. Você escolhe a conta no navegador e volta ao app para usar as ações disponíveis.

[Consulte o catálogo](/product/connections/managed-connections) e o [passo a passo de conexão](/support/sources).

## Quando aparecem MCP, API e pasta local

**MCP** é uma forma de um serviço disponibilizar ferramentas para o G4 OS. **API** é uma conexão com as operações oferecidas por um sistema. **Pasta local** aponta para arquivos no computador.

Essas opções ajudam quando a integração desejada não está no catálogo gerenciado. Você pode pedir ajuda para configurá-las; não precisa aprender os nomes técnicos para fazer uma tarefa com uma conexão já pronta.

## Conferir o alcance

Leia a descrição do item e comece com uma consulta pequena. A conta conectada, as ações oferecidas pela integração e as [permissões da sessão](/support/permissions) definem o que poderá ser feito.
