---
title: "Rotinas recorrentes"
description: "Transforme uma tarefa validada em uma rotina que você consegue acompanhar."
---

Antes de automatizar, execute uma vez e confira o resultado. Uma boa rotina tem fonte definida, período claro e uma saída fácil de revisar.

| Trabalho | Próximo passo |
| --- | --- |
| Resumo semanal de tarefas | Agendar uma nova sessão toda segunda. |
| Conferir uma resposta pendente | Criar um vigia com alvo e prazo para parar. |
| Atualizar indicadores | Usar um dashboard salvo em uma rotina. |
| Repetir um método de análise | Salvar o passo a passo como workflow. |

## Exemplo

> Toda sexta às 16h, resuma as entregas desta semana a partir da fonte de tarefas selecionada. Mostre concluídas, pendências e itens sem responsável em uma nova sessão. Não altere tarefas nem envie o resumo para outras pessoas.

Confira horário, fuso, acesso às fontes e histórico de execução. O computador precisa estar disponível para a rotina local funcionar no horário previsto.
