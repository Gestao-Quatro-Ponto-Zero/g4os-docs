## O que é Ferramentas

`Ferramentas` é o hub do workspace para tudo que amplia a capacidade operacional do G4 OS.

É ali que você encontra:

- **Conexões** para APIs, MCPs, pastas locais, conectores gerenciados e agentes G4
- **Skills** para instruções reutilizáveis aplicadas a tarefas específicas
- **Workflows** para processos versionados que rodam por comando
- **Dashboards** para painéis nativos salvos no workspace

## Como usar

Use esta área quando quiser revisar o que o workspace já tem disponível antes de abrir uma sessão, criar uma automação ou pedir para o agente executar um fluxo.

Na prática, ela ajuda a responder perguntas como:

- quais conexões este workspace pode usar?
- quais skills e workflows já existem?
- existe um dashboard salvo para este assunto?
- a integração que eu preciso está conectada, exige autenticação ou tem problema de validação?

## Abas principais

### Conexões

Mostra integrações reutilizáveis, incluindo conectores gerenciados, MCPs, APIs, pastas locais e agentes. Para o guia detalhado, veja [Conexões](/support/sources).

### Skills

Mostra skills disponíveis no workspace. Skills são instruções especializadas que podem ser acionadas pelo agente quando o tipo de trabalho combina com a descrição da skill. Veja [Skills](/support/skills).

### Workflows

Mostra processos reutilizáveis, normalmente acionados por `/nome-do-workflow` no input da sessão. Veja [Workflows](/support/workflows).

### Dashboards

Mostra painéis nativos salvos no workspace. Dashboards preservam definição, fontes, layout e último refresh. Veja [Dashboards](/support/dashboards).

## Dica prática

Quando uma sessão não encontra uma ferramenta ou o agente diz que não tem acesso a uma capacidade, comece por `Ferramentas`. Verifique primeiro se a conexão, skill, workflow ou dashboard existe no workspace e só depois investigue permissões, credenciais ou automações.
