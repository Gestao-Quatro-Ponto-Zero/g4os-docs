Abra **Configurações > Workspace** e confira o nome do ambiente ativo antes de alterar algo.

| Controle | Quando usar |
| --- | --- |
| Nome e ícone | Identificar um contexto pessoal, uma área ou uma operação. |
| Modo de permissão padrão | Definir como novas sessões começam. |
| Brain | Conferir e configurar a memória deste workspace. |
| Company Context | Vincular o ambiente a uma empresa à qual você tem acesso. |
| Telegram | Configurar o bot e conferir chats pareados. |
| Fontes padrão | Escolher conexões habilitadas em novas sessões. |
| Alternância de modos | Escolher quais modos entram no ciclo do atalho de permissões. |
| Recomendações de parceiros | Ajustar as sugestões apresentadas durante o trabalho. |
| Avançado | Definir pasta de trabalho e disponibilidade de servidores MCP locais. |

## Escolher padrões úteis

Habilite como padrão apenas fontes que usa com frequência. Antes de uma tarefa, confira quais estão conectadas naquela sessão. O padrão não concede acesso a uma conta que ainda não foi autenticada.

Para rotinas novas, comece com [Perguntar](/support/permissions) e avalie cada solicitação de ação. Confira o modo ativo em **Informações do chat > Detalhes**.

## Pastas e arquivos

A pasta de trabalho orienta onde o agente procura e cria arquivos. Escolha uma pasta relacionada à tarefa. Ela não é a mesma coisa que um [projeto](/support/projects), que organiza conversas, marcos e referências dentro do app.

## Conta e empresa

Conectar o workspace a uma empresa disponibiliza o contexto e os recursos permitidos para sua conta. Isso não transfere automaticamente todos os seus arquivos para a empresa nem libera todos os documentos para todos os membros.
