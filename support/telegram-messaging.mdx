---
title: "Conversar pelo Telegram"
description: "Vincule sessões a um chat privado com seu bot e continue pelo celular."
---

O Telegram pode funcionar como uma entrada para sessões do workspace. O G4 OS continua executando no desktop, que precisa estar aberto e conectado.

## Configurar o bot

1. No Telegram, use o **BotFather** para criar um bot pelo comando `/newbot`.
2. Guarde o token entregue pelo Telegram.
3. No G4 OS, abra **Configurações > Workspace > Telegram**.
4. Cole o token no campo apropriado, salve e confira o estado **online**.

Não coloque o token em uma mensagem para o agente ou em uma captura. Ele dá controle sobre o bot.

## Vincular uma sessão

1. Abra uma sessão no G4 OS e escolha **Conectar ao Telegram** no menu da sessão.
2. Gere o código de pareamento.
3. Em uma **conversa privada** com seu bot, envie o comando `/pair` com o código apresentado.
4. Aguarde a confirmação e confira qual sessão ficou ativa.

As mensagens enviadas ao bot seguem para a sessão ativa, e as respostas voltam pelo Telegram. Um chat pode ter várias sessões vinculadas, mas você escolhe qual está ativa.

## Comandos no Telegram

| Comando | Ação |
| --- | --- |
| `/start` | Mostrar a orientação inicial do bot. |
| `/help` | Listar comandos disponíveis. |
| `/pair código` | Vincular e ativar uma sessão com o código do desktop. |
| `/sessions` | Listar sessões vinculadas. |
| `/use número` | Trocar para uma das sessões listadas. |
| `/new nome` | Criar, vincular e ativar uma nova sessão após o pareamento. |
| `/status` | Conferir a sessão ativa. |
| `/stop` | Interromper a execução ativa. |
| `/unbind` | Desvincular a sessão ativa deste chat. |
| `/unbind all` | Desvincular todas as sessões deste chat. |

Estes são comandos do bot, diferentes do menu `/` no campo de mensagem do desktop.

## Arquivos e limites

O fluxo aceita fotos e documentos compatíveis, como PDF, Office e texto, dentro dos limites apresentados. Mensagens de voz, arquivos de áudio e vídeo ainda não são aceitos por essa entrada. Para voz, use [ditado ou Desk no app](/product/voice-input).

Acompanhe pedidos de informação ou aprovação e leia o que será executado antes de responder. Revise a sessão ativa antes de enviar dados de outro assunto.

## Encerrar o vínculo

Veja **Chats pareados** nas configurações do Telegram. **Desconectar** interrompe o serviço mantendo a configuração; **Remover** apaga o token configurado e desfaz os vínculos. Desvincular um chat não apaga o histórico da sessão no G4 OS.
