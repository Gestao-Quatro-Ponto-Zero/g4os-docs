Abra a referência de atalhos com `⌘ /` no Mac ou `Ctrl /` no Windows/Linux. Alguns atalhos dependem de onde está o foco: chat, busca ou lista de sessões.

## No campo de mensagem

| Digite | Para quê |
| --- | --- |
| `@` | Selecionar recursos como fontes, skills, workflows, dashboards, arquivos e agentes disponíveis. |
| `#` | Selecionar uma tag da sessão. |
| `>` | Referenciar outra sessão. |
| `/` | Abrir comandos operacionais, como modos de permissão e opções disponíveis naquela sessão. |

Selecione um item do menu e complete o pedido. Para workflows, prefira `@`; a chamada antiga `/nome-do-workflow` continua compatível. Não há uma lista universal de comandos como `/help` ou `/clear`: use o que o menu realmente oferece.

Os comandos de permissão correspondem a **Explorar** (`/safe`), **Perguntar** (`/ask`) e **Executar** (`/allow-all`). Pro e opções de pasta só aparecem quando aplicáveis. Trocar o modo muda a autonomia da sessão; leia [Permissões](/support/permissions).

## Ações gerais

| Ação | Mac | Windows / Linux |
| --- | --- | --- |
| Nova sessão | `⌘ N` | `Ctrl N` |
| Configurações | `⌘ ,` | `Ctrl ,` |
| Buscar | `⌘ F` | `Ctrl F` |
| Referência de atalhos | `⌘ /` | `Ctrl /` |
| Nova janela | `⌘ Shift N` | `Ctrl Shift N` |
| Alternar tema claro/escuro | `⌘ Shift A` | `Ctrl Shift A` |
| Sair do aplicativo | `⌘ Q` | `Ctrl Q` |
| Abrir Desk | `⌘ Shift J` | `Ctrl Shift J` |

## Navegação e foco

| Ação | Mac | Windows / Linux |
| --- | --- | --- |
| Focar navegação lateral | `⌘ 1` | `Ctrl 1` |
| Focar lista de sessões | `⌘ 2` | `Ctrl 2` |
| Focar chat | `⌘ 3` | `Ctrl 3` |
| Próxima área ou controle | `Tab` | `Tab` |
| Voltar | `⌘ [` ou `⌘ ←` | `Ctrl [` ou `Ctrl ←` |
| Avançar | `⌘ ]` ou `⌘ →` | `Ctrl ]` ou `Ctrl →` |
| Mostrar/ocultar barra lateral | `⌘ B` | `Ctrl B` |
| Modo foco | `⌘ .` | `Ctrl .` |

## Sessões e busca

| Ação | Atalho |
| --- | --- |
| Selecionar todas as sessões, com foco na lista | `⌘ A` / `Ctrl A` |
| Limpar seleção na lista | `Esc` |
| Interromper a tarefa no chat | Pressione `Esc` **duas vezes**, sem outro diálogo aberto. |
| Alternar modos de permissão no chat | `Shift Tab` |
| Próximo resultado da busca | `⌘ G` / `Ctrl G` |
| Resultado anterior da busca | `⌘ Shift G` / `Ctrl Shift G` |

Com foco no campo da busca, `Enter` e `Shift Enter` também navegam pelos resultados. O ciclo de modos pode ser configurado no workspace.
