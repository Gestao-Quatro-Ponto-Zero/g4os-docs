Em **Ferramentas > Dashboards**, você encontra painéis salvos no workspace. Eles podem reunir indicadores, tabelas e gráficos de diferentes conexões.

<Note>Dashboards estão em beta. As fontes e ações disponíveis dependem do seu workspace.</Note>

## Criar a partir de uma pergunta

1. Conecte a fonte que contém os dados e habilite-a na sessão.
2. Diga quais indicadores precisa, como calcular cada um e qual período usar.
3. Peça para salvar como dashboard reutilizável.
4. Abra o painel na área de Dashboards e confira valores, filtros e data da última atualização.

> Crie um dashboard salvo de entregas do trimestre. Use a fonte de tarefas que selecionei. Mostre total, concluídas, atrasadas e uma tabela por responsável. Considere atrasada somente uma tarefa não concluída com vencimento anterior a hoje. Mostre o período e a última atualização.

## Reabrir e atualizar

> Abra o dashboard de entregas do trimestre e atualize os dados mantendo o layout.

A atualização usa as fontes e os parâmetros salvos. Para mudar indicadores, filtros ou aparência, peça uma **edição do dashboard**. Uma resposta com gráfico no chat não é necessariamente um dashboard salvo.

## Ler o resultado com cuidado

Confira se a última execução foi concluída, falhou ou ficou bloqueada. Um painel aberto pode mostrar dados de uma execução anterior. Se uma conexão perdeu acesso, reconecte-a e atualize novamente.

As tabelas podem oferecer ordenação, busca e ações de copiar ou baixar CSV. A exportação leva os dados apresentados naquele momento; atualize o painel antes de distribuir o arquivo.

Para atualização recorrente, combine o painel salvo com uma [automação](/support/automation). [Abrir Dashboards no app](g4os://dashboards).
